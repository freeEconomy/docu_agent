# Story cover artwork

Thirty original illustrations were generated for Fun To Run during development on 2026-10-21, in a traditional watercolor and engraving style. These are new artwork inspired by public-domain story plots, not scans of historical editions or reproductions of a modern publisher's cover.

Files use the corresponding tale ID from `lib/forest/adventures.ts` and `lib/forest/classic-expansion.ts`. The artwork was produced in three 5-by-2 sheets, extracted into individual illustrations, cropped to 4:3 with subject-aware positioning, and saved locally as optimized WebP files. The book title, genre and difficulty are rendered separately by React for legibility at mobile sizes.

The website serves these static local files. It does not call an image-generation API at runtime. The CC0 photo credits for vocabulary photographs are separate and do not apply to this artwork.
