# DocuMind Stitch 디자인 반영 기록

대상은 `7162910529939285378` 프로젝트의 매핑된 화면 6개입니다. Stitch 프로젝트의 최종 수정 시각은 2026-10-18 01:00 KST(2026-10-17T16:00:09Z)입니다.

## 원본 비교 결과

공식 Stitch 파일 API에서 인증 후 HTML 6개를 모두 내려받아 최신 main에 있는 원본 HTML과 바이트 단위로 비교했습니다. **6개 모두 동일**하여 Stitch에서 새로 변경된 HTML은 없습니다. `.stitch/snapshot.json`에 실제 검증한 화면 ID와 HTML SHA-256을 기록했습니다.

로그인/가입의 Stitch API PNG 2개는 응답의 base64 `dataString`을 해석하여 원본을 확인하고 최신 PNG로 갱신했습니다. 나머지 4개 PNG의 CDN 다운로드는 현재 실행 환경에서 차단되어 기존 파일을 유지했습니다. 이 4개 화면은 최신 HTML이 저장소와 동일한 것을 확인했으며, PNG를 새로 내려받았다고 간주하지 않습니다.

## 앱과 원본 사이의 차이 반영

- 로그인: 재사용 가능한 Google/Microsoft/Okta 표시, 강조 아이콘 타일, 보안 디자인 카드의 보조 설명을 추가했습니다.
- 가입: 원본의 기업 SSO 버튼, 조직·RAG 사용 목적 입력, 4개 비밀번호 강도 조건, 약관 전체/개별 동의와 안내 창을 구현했습니다.
- 기존 3단계 가입 흐름을 유지하면서 이전 단계로 돌아가도 이름·이메일·조직·사용 목적이 보존되도록 했습니다. 이메일 도메인 안내는 데모 접근을 막지 않습니다.
- 로그인/가입 내비게이션의 현재 페이지 표시를 수정하고, 모바일에서 SSO 버튼과 강도 조건을 한 열/두 열로 재배치했습니다.
- 채팅, 문서 관리·업로드, 원문/청크 분석, 관리자 기능은 기존 동작을 유지합니다. 실제 인증·RAG 연동 상태는 계속 Mock으로 표시합니다.

원본 HTML을 앱에 직접 삽입하거나 원본 스크립트를 실행하지 않고 React 컴포넌트로 적용했습니다. 이미지 렌더링 해상도 변화와 제품 기능 변경은 구분합니다.
