# Gemini 무료 계층 문서 질의응답

Google OAuth 로그인과 Gemini API는 별도 서비스입니다. OAuth Client Secret을 AI 키로 사용하지 않습니다. OpenAI 키·OpenAI 호출·자동 유료 모델 전환은 사용하지 않습니다.

## 설정

1. [Google AI Studio API Keys](https://aistudio.google.com/api-keys)에서 **Free tier 프로젝트**의 Gemini API 키를 만듭니다. 프로젝트에 유료 결제를 연결하지 마세요. 같은 모델이라도 프로젝트가 Paid tier이면 호출이 과금될 수 있으며 앱은 키만으로 결제 등급을 판별할 수 없습니다.
2. Vercel `docu_agent` → Settings → Environment Variables → Production에 `GEMINI_API_KEY`로 등록한 뒤 Redeploy합니다. 키는 채팅·Git·공개 환경 변수에 넣지 않습니다.
3. `npm run db:migrate`로 스키마 버전 3을 설치합니다. 기존 문서와 대화는 보존합니다.
4. 채팅에서 **문서 선택**을 눌러 외부 AI에 전달해도 되는 문서를 지정합니다. 검색 준비는 선택한 본인 문서에 대해서만 진행하며 전체 문서를 자동 전송하지 않습니다. 과거에 분석한 문서도 첫 질문 전 검색 준비 단계에서 임베딩하므로 다시 업로드할 필요가 없습니다.

[Google 가격표](https://ai.google.dev/gemini-api/docs/pricing)에서 무료 계층이 있는 `gemini-2.5-flash-lite`(답변)와 `gemini-embedding-2`(텍스트 임베딩)를 사용합니다. 무료 할당량과 제공 모델은 변경될 수 있으므로 프로젝트의 실제 AI Studio 한도를 확인하세요. 웹 검색·Grounding·File Search·유료 Batch 작업은 호출하지 않습니다. `batchEmbedContents`는 여러 텍스트를 동기식으로 임베딩하는 표준 API이며 유료 비동기 Batch 작업과 다릅니다.

**무료 API는 입력·응답을 제품 개선에 사용하고 사람이 검토할 수 있습니다. Google 약관은 개인정보·기밀정보·민감정보를 무료 서비스에 제출하지 말라고 명시합니다.** 공개 가능한 자료로 사용하세요. 회사 인사·고객·계약 문서에는 이를 그대로 적용하지 마세요. [Gemini API 약관](https://ai.google.dev/gemini-api/terms#unpaid-services)

## 검색과 답변

- 텍스트를 최대 1,200자로 분할하되 문단 경계를 우선하고 180자를 겹칩니다. 이미 분석된 문서는 기존 청크를 그대로 사용할 수 있습니다.
- 정규화한 512차원 임베딩을 기존 Neon의 `real[]`에 저장하고 코사인 유사도를 정확 계산합니다. 초기 규모에서는 별도 벡터 서비스·확장 설치가 필요 없습니다. 문서가 많아지면 스캔 비용과 지연이 증가하므로 pgvector/HNSW 전환을 검토해야 합니다. 현재는 근사 최근접 검색 인덱스를 사용하지 않습니다.
- 벡터 검색과 키워드 검색의 순위를 결합해 중복을 제거하고 최대 4개 청크만 답변 생성에 전달합니다. 외부 LLM을 이용한 질문 재작성·재순위화는 하지 않습니다.
- 답변은 최대 출력 900토큰으로 제한하고 실제 사용한 원문 일부만 표시합니다. 인용 문자열이 원문에 그대로 존재하는지, 출처 번호가 유효한지 서버에서 확인합니다. 이는 인용 일치를 검증하는 것이며 모든 주장의 의미적 정확성을 보장하지는 않습니다.
- 근거가 없으면 없다고 답합니다. 키·할당량·응답 검증 실패 시 원문 나열이나 다른 제공자로 대체하지 않고 명확히 오류를 안내합니다. 질문은 현재 질문과 선택 문서를 기준으로 처리하며 이전 대화 전체를 자동 전달하지 않습니다.

## 비용·할당량 보호

- 문서/질문 임베딩은 계정·모델·텍스트 해시별로 재사용합니다. 한 번에 최대 32개 텍스트를 처리합니다. 같은 문서의 재분석 때 내용이 같으면 저장된 임베딩을 재사용합니다.
- 같은 질문·같은 문서 버전의 답변은 1시간 캐시합니다. 계정 간 캐시는 공유하지 않습니다. 문서 선택·이름·내용·분석 버전이 바뀌거나 문서가 삭제되면 이전 캐시를 사용하지 않습니다.
- 새 AI 질문은 기본 **계정당 10회/일, 전체 20회/일**입니다. 캐시 적중은 추가 AI 호출이나 질문 한도를 소비하지 않습니다. 입력 임베딩은 기본 **계정당 20만 자/일, 전체 100만 자/일**로 제한합니다. 캐시된 텍스트는 차감하지 않습니다. 한도 계산은 UTC 날짜 기준입니다.
- 요청 전 DB에서 원자적으로 사용량을 예약하므로 동시 요청도 한도를 넘기지 못합니다. 외부 오류가 난 요청은 보수적으로 사용량을 돌려주지 않습니다. 동시 동일 요청은 중복 외부 호출이 생길 수 있지만 각 호출은 한도에 포함됩니다.
- 필요하면 `.env.example`의 `RAG_DAILY_QUESTIONS`, `RAG_GLOBAL_DAILY_QUESTIONS`, `RAG_DAILY_EMBEDDING_CHARACTERS`, `RAG_GLOBAL_DAILY_EMBEDDING_CHARACTERS`를 조정합니다. Google의 실제 무료 한도가 이보다 작으면 제공자의 429 응답에서 먼저 중단합니다. 자동 재시도·추가 과금 동의·결제 연결은 하지 않습니다.
- **앱의 호출 한도는 달러 단위 지출 상한이나 무료 등급 보증이 아닙니다.** 무료로 사용하려면 Google 프로젝트의 Free tier 유지가 필요합니다. Neon·Vercel 저장소와 실행 비용은 각각의 무료 할당량과 요금 정책을 따릅니다.

## 검증

`npm run test:backend`는 실제 SQL 벡터 유사도, 계정 격리, 임베딩/답변 재사용, 변경·삭제 후 캐시 무효화, 동시 요청 한도, 허위 인용 거부를 검사합니다. 브라우저 테스트의 Gemini 응답은 격리된 모형 응답이며 실제 모델 답변의 품질 검증은 아닙니다. 실제 검증은 Gemini 키 연결 후 공개 가능한 문서로 수행합니다. Codex에서 직접 호출하려면 `generativelanguage.googleapis.com` 네트워크 허용과 안전한 `GEMINI_API_KEY` 설정도 별도로 필요합니다.
