# 단어숲 — 정적인 실사 사진으로 배우는 생활 영어

현재 서비스는 동물·동화·애니메이션 대신 집/학교/외출에서 사용하는 영어에 집중한다. 기존 한국어/움직이는 그림책 기록은 `docs/archive/wordforest-korean-history.md`에 남겼으며 현재 기능 설명이 아니다.

## 학습 범위

- 사진 단어 10개: bus, train, car, airplane, laptop, chair, bowl, sign, building, window.
- 주제: 집에서, 학교에서, 밖에서. 영어·한국어·함께 쓰는 영어 낱말로 검색.
- 단어별 기본/생활/부탁·질문 3단계 × 2문장 = 예문 60개. 영어 듣기와 한국어 뜻 표시/숨기기.
- 단어별 6장면 상황 대화 10개. 같은 사물의 참고 사진을 사용하며 대화 장면을 직접 촬영한 사진처럼 표시하지 않는다.
- 사진과 낱말, 문장 완성, 표현의 뜻, 대화 이해, 상황 순서 5문제. 연습 즉시 해설과 복습 마지막 채점.
- 단어별 한국 날짜 하루 첫 완료에만 보상 10개. 반복 풀이로 보상이 늘어나지 않는다.
- 동물 캐릭터 대신 이름·색상·책/나침반/연필 표식으로 학습카드를 꾸민다.
- 부모 확인, 단계/영어 속도/참고 시간 목표, 복습 추천, 최근 기록, 사진별 출처와 이용 조건, 영어 기록만 초기화.

## 사진의 출처와 라이선스

9개의 실제 촬영 사진을 로컬 `public/english-photos/`에 저장했다. 건물과 창문 수업은 같은 건물 사진을 사용한다. 일러스트·AI 이미지·영상·외부 이미지 핫링크는 사용하지 않는다.

모든 원본은 Wikimedia Commons 파일 설명 또는 공개 사진 코퍼스의 개별 매니페스트에서 CC0 1.0으로 공개된 자료다. 원본을 배포하는 공개 저장소 [libphash-site-corpus](https://github.com/gudoshnikovn/libphash-site-corpus)의 사진과 `corpus_photos.tsv`를 읽어 SHA-256을 대조했다. 허용된 GitHub 원본 배포 경로에서 다운로드했다. Commons 파일 설명도 웹 조회로 확인했으며, 자동차 사진은 파일 설명 조회 도구가 응답하지 않아 코퍼스의 개별 CC0 선언과 해시를 근거로 기록했다.

`lib/forest/photo-credits.json`에 원문 파일명, 저작자/촬영자, CC0 링크, 원문 페이지, 배포 경로, 원본/로컬 SHA-256, 변경 사항을 기록했다. 의자 사진은 제작자 Georges Jacob과 촬영자 Jebulon을 구분한다. 크기를 최대 1100px로 줄이고 JPEG 압축·EXIF 제거만 수행했으며 사물 합성은 하지 않았다. 총 사진 용량은 약 1.84MB다.

CC0는 촬영물의 이용 조건이다. 사진 속 물건과 상표에 관한 모든 별도 권리까지 포기되었다고 주장하지 않는다. 노트북·의자는 예전 모델/장식 의자이며 현대 교실 사진이라고 표시하지 않는다. 표지판은 제한 속도 표지판으로, 정지 표지판으로 오인시키지 않는다. bowl의 사진은 그릇 모양을 가르치며 내용물을 먹으라고 안내하지 않는다.

## 비용과 개인정보

외부 AI·임베딩·TTS·이미지 생성 API, 이미지 CDN, 계정/DB 호출 없이 정적 콘텐츠와 로컬 사진으로 학습한다. 사이트의 AI API 비용은 0원이며 호스팅/전송 비용은 별개다.

영어 듣기는 브라우저 Web Speech API를 사용한다. en-US를 우선 선택하고 다른 영어 음성을 대안으로 사용한다. 한국어 음성으로 영어를 잘못 읽지 않는다. 영어 음성이 없으면 안내하고 글 학습을 계속한다. OS/브라우저가 음성을 온라인 합성할 수 있으므로 완전 오프라인 음성까지 보장하지는 않는다. 녹음·발음 판정·마이크 전송은 없다.

영어 프로필 키는 `wordforest-english-v1`이다. 영어 프로필이 없을 때만 기존 `wordforest-v1`에서 별명·나뭇잎을 가져오고 기존 키는 변경하지 않는다. 기존 동물/한글 수업은 현재 화면에 표시하지 않는다. 영어 기록 삭제 시에도 기존 한글 키는 남는다. 기기 간 동기화는 없다.

## 검증

`npm run build`

`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test -- tests/forest.spec.ts`

PC·모바일에서 10개 낱말의 실제 사진 로드(naturalWidth), 정적 화면/애니메이션 없음, 영어/한국어 검색, 단계와 뜻 숨기기, 6장면 대화와 5문제 퀴즈, 정답 해설, 학습카드와 새로고침 유지, 영어 음성 선택/미지원 처리, 중복 보상 방지, 기존 기록 보존과 영어만 초기화, API/외부 도메인 요청 0건을 확인한다. 영어 음성 테스트는 브라우저 음성 공급자 대역으로 언어와 요청 텍스트를 확인하며, 실제 기기의 목소리 품질은 기기마다 다르다.

기존 DocuMind 서버/비공개 문서 경로는 유지하지만 단어숲 루트에서는 해당 기능을 마운트하거나 호출하지 않는다.
