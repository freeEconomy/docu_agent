# 단어숲

Stitch 프로젝트: https://stitch.withgoogle.com/projects/18401851852860587539

2026-10-20에 5개 화면의 HTML을 읽어 `design/wordforest/`에 보관했다. 원본 HTML을 실행하거나 외부 CDN 스크립트를 삽입하지 않고 React 컴포넌트와 로컬 CSS/SVG로 구현했다. 색상·하단 내비게이션·큰 카드와 캐릭터 중심의 흐름을 반영했다. 시안에 있는 100단어, 경험치와 샘플 누적 기록은 실제 준비된 10단어와 기기 저장 기록으로 대체했다.

## 학습

- `/`: 로그인 없는 단어숲. `lib/forest/content.ts`의 한국어 단어 10개, 수준별 예문 30개, 4페이지 동화 10편, 단어·빈칸·동화 이해 퀴즈.
- 캐릭터: SVG 동물·색상·장식 조합과 별명. 기본 장식 무료, 왕관은 누적 나뭇잎 20개로 열림(차감 없음).
- 퀴즈: 연습은 오답 힌트와 재시도, 복습 도전은 마지막에 정답 표시. 단어별 한국 날짜 하루 첫 완료에만 10개 보상. 반복 클릭/재풀이로 추가 보상하지 않음.
- 기록: `wordforest-v1` localStorage. 캐릭터·단어·읽던 쪽·수준·속도·목표·퀴즈 기록 유지. 기록은 최근 300개, 부모 목록에는 최근 10개 표시. 복습 목록은 단어별 마지막 결과 기준.
- 부모 화면: 산술 문제로 진입을 구분하며 인증/보안 잠금이 아니다. 기본 1개 프로필, 기록 삭제에는 재확인. 학습 시간 목표는 참고용이며 자동 사용시간 측정·강제 제한 기능은 없다.

## 비용과 개인정보

단어숲에서는 외부 AI API, 임베딩, TTS API, 이미지 생성 API, 계정/데이터베이스 요청을 하지 않는다. 무료 할당량이나 API 키가 필요 없다. 폰트·그림·캐릭터는 로컬 파일/코드로 제공한다. 서버 호스팅 비용과 AI API 비용은 별개다.

음성은 기기의 Web Speech API `SpeechSynthesis`와 한국어 voice를 사용하며, 한국어 voice가 없으면 안내하고 글 학습을 계속한다. 브라우저/OS에 따라 음성 지원·목소리가 다르고, voice 공급자는 기기 정책에 따라 온라인 합성을 사용할 수도 있다. 따라서 사이트의 외부 TTS API 비용은 없지만 모든 기기에서 음성까지 완전 오프라인 작동한다고 보장하지 않는다. 음성 입력·녹음·전송 기능은 없다.

기기 간 동기화·회원 계정·진도 서버 저장은 없다. 브라우저 데이터 삭제 시 기록이 사라진다. 작성한 콘텐츠는 출시 전 교육 전문가/보호자의 추가 검토를 권장한다. 새로운 단어는 즉석 생성하지 않고 미지원 안내를 표시한다.

기존 DocuMind의 `/chat`, `/documents`, 로그인 및 서버 API는 기존 데이터 보존을 위해 유지했다. 해당 경로의 기존 AI 기능은 별개이며, 단어숲의 RouteProvider는 WorkspaceProvider를 마운트하지 않아 기존 Gemini/Neon API를 호출하지 않는다.
