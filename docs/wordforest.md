# 단어숲

Stitch 프로젝트: https://stitch.withgoogle.com/projects/18401851852860587539

2026-10-20에 5개 화면의 HTML을 읽어 `design/wordforest/`에 보관했다. 원본 HTML을 실행하거나 외부 CDN 스크립트를 삽입하지 않고 React 컴포넌트와 로컬 CSS/SVG로 구현했다. 색상·하단 내비게이션·큰 카드와 탐험과 독서 중심의 흐름을 반영했다. 시안에 있는 100단어, 경험치와 샘플 누적 기록은 실제 준비된 10단어와 기기 저장 기록으로 대체했다.

## 학습

- `/`: 로그인 없는 단어숲. `lib/forest/content.ts`의 한국어 단어 10개, 확장 어휘 30개, 수준별 예문 60개, 6페이지 동화 10편(각 약 650~830자), 어휘·문맥·이유·순서·추론 5문제 퀴즈.
- 캐릭터: SVG 동물·색상·장식 조합과 별명. 기본 장식 무료, 왕관은 누적 나뭇잎 20개로 열림(차감 없음).
- 퀴즈: 연습은 오답 힌트와 재시도, 복습 도전은 마지막에 정답 표시. 단어별 한국 날짜 하루 첫 완료에만 10개 보상. 반복 클릭/재풀이로 추가 보상하지 않음.
- 기록: `wordforest-v1` localStorage. 캐릭터·단어·읽던 쪽·수준·속도·목표·퀴즈 기록 유지. 기록은 최근 300개, 부모 목록에는 최근 10개 표시. 복습 목록은 단어별 마지막 결과 기준.
- 부모 화면: 산술 문제로 진입을 구분하며 인증/보안 잠금이 아니다. 기본 1개 프로필, 기록 삭제에는 재확인. 학습 시간 목표는 참고용이며 자동 사용시간 측정·강제 제한 기능은 없다.

## 비용과 개인정보

단어숲에서는 외부 AI API, 임베딩, TTS API, 이미지 생성 API, 계정/데이터베이스 요청을 하지 않는다. 무료 할당량이나 API 키가 필요 없다. 폰트·그림·캐릭터는 로컬 파일/코드로 제공한다. 서버 호스팅 비용과 AI API 비용은 별개다.

음성은 기기의 Web Speech API `SpeechSynthesis`와 한국어 voice를 사용하며, 한국어 voice가 없으면 안내하고 글 학습을 계속한다. 브라우저/OS에 따라 음성 지원·목소리가 다르고, voice 공급자는 기기 정책에 따라 온라인 합성을 사용할 수도 있다. 따라서 사이트의 외부 TTS API 비용은 없지만 모든 기기에서 음성까지 완전 오프라인 작동한다고 보장하지 않는다. 음성 입력·녹음·전송 기능은 없다.

기기 간 동기화·회원 계정·진도 서버 저장은 없다. 브라우저 데이터 삭제 시 기록이 사라진다. 작성한 콘텐츠는 출시 전 교육 전문가/보호자의 추가 검토를 권장한다. 새로운 단어는 즉석 생성하지 않고 미지원 안내를 표시한다.

기존 DocuMind의 `/chat`, `/documents`, 로그인 및 서버 API는 기존 데이터 보존을 위해 유지했다. 해당 경로의 기존 AI 기능은 별개이며, 단어숲의 RouteProvider는 WorkspaceProvider를 마운트하지 않아 기존 Gemini/Neon API를 호출하지 않는다.

## 7세 읽기 개편과 영상

변경된 Stitch의 어휘 설명·과수원 문장·긴 동화·마음과 까닭을 묻는 퀴즈를 다시 조회해 반영했다. 단순히 글자 수만 늘리지 않고 발단, 문제, 탐색, 전환, 해결, 성장의 6단계로 10편을 다시 작성했다. 단어와 함께 수확·배려·관찰·협력·호기심·생태계·증발·굴절·대비·계획 등을 학습한다. 세 문장 수준은 탄탄 읽기/생각 읽기/도전 읽기이며 각 수준에 다른 문장 1개를 추가했다. 확장 어휘로 검색하면 관련 단어와 해당 뜻을 표시한다.

3문제였던 기존 기록에는 분모 3을 유지하고, 새 기록은 total=5를 저장한다. 기존 캐릭터·나뭇잎·기록을 초기화하지 않는다. 동화의 페이지 수와 진행률은 콘텐츠 길이를 따른다.

영화 같은 3D 애니메이션을 원하는 사용자 선택을 반영해, 영상 제작용 캐릭터는 아이 탐험가로 설정하고 본문의 주요 친구도 어린이 등장인물로 바꾸었다. 홈과 동화의 큰 동물 마스코트는 탐험 풍경 SVG로 교체했다. 이 SVG는 AI 동영상이 아니며 동영상처럼 표시하지 않는다. 캐릭터 꾸미기는 별도 메뉴에 유지한다.

`lib/forest/media.ts`의 storyVideos에 미리 제작한 장면별 MP4와 선택적 자막/포스터를 등록하면 StoryStage에서 브라우저 기본 재생기를 제공한다. 현재 등록된 영상은 없으며, 영상 생성·유료 API 호출·자동재생을 하지 않는다. 파일이 없을 때 가짜 재생 버튼을 표시하지 않으며, 등록된 영상의 로딩 오류 시 글 읽기로 이어갈 수 있다. 영상 제작과 배포 대역폭은 무료 AI 호출과 별도의 비용/사용량 제한이 있을 수 있다.

## 움직이는 그림책

`lib/forest/scenes.ts`에 10편 × 6쪽의 장면 설명을 두고, `StoryStage`가 주제별 과수원·소풍·학교·다리·도서관·공원·물 실험·굴절 관찰·날씨·전시회 배경을 SVG로 그린다. 어린이 탐험가, 바구니와 수확 도구, 씨앗·상자·다리 모형·물 접시·빨대·쉼터·그림 등을 장면에 맞게 보여 준다. AI 영상이나 렌더링된 3D 영화가 아니라 로컬 코드로 그린 2D 그림책이다.

자동재생 없이 사용자가 장면 재생을 누르면 바람·나무·물결·비·물의 증발·사과와 도구 등의 CSS 움직임이 실행된다. 4초마다 3개의 관찰 자세가 순환하며, 장면 넘기기로 수동 조작할 수 있다. 멈춤/처음 장면, 페이지 전환 시 초기화, 탭이 숨겨질 때 애니메이션/타이머 일시 정지를 제공한다. `prefers-reduced-motion`에서는 연속 움직임을 끄고 수동 장면 조작과 글·음성 학습을 유지한다.

함께 듣기와 이 쪽 듣기는 현재 페이지의 브라우저 읽어주기를 사용한다. 읽기 시작·종료에 장면 재생·멈춤을 연결하지만 단어별 립싱크나 음성 타임코드 동기화 기능은 아니다. 한국어 음성이 없으면 기존 미지원 안내를 제공한다. 홈의 미리보기는 움직이지 않는다.

검증: PC/모바일에서 재생·멈춤의 실제 CSS animationPlayState, 장면 변화와 페이지 초기화, 탭 가림 시 정지, 동작 줄이기, 현재 페이지 낭독 연결을 확인한다. 학습 요청에 AI/서버 API/MP4 요청이 없는 것도 검사한다. 영상 생성 API·유료 애니메이션 라이브러리·외부 이미지 CDN을 추가하지 않았다.
