# Fun To Run — 사진과 학습 친구로 배우는 생활 영어

현재 서비스는 7세 유치원생이 집·유치원·놀이터에서 사용할 생활 영어를 다룬다. 스포츠·놀이·놀이터·음식·동물 주제를 추가했으며, 동물도 실제 촬영 사진으로 배운다. 기존 한국어/움직이는 그림책 기록은 `docs/archive/wordforest-korean-history.md`에 남겼으며 현재 기능 설명이 아니다.

## 학습 범위

- 사진 단어 40개: 기존 생활 단어 10개에 주제별 6개씩 총 30개를 추가했다.
  - 스포츠: ball, soccer, basketball, tennis, swimming, bicycle
  - 놀이: blocks, puzzle, kite, bubbles, teddy bear, doll
  - 놀이터: playground, slide, swing, seesaw, sandbox, ladder
  - 음식: apple, banana, bread, egg, milk, rice
  - 동물: dog, cat, rabbit, duck, horse, elephant
- 주제: 집에서, 학교에서, 밖에서, 스포츠, 놀이, 놀이터, 음식, 동물. 영어·한국어·함께 쓰는 영어 낱말로 검색하며 정확한 단어 이름을 연관 표현보다 우선한다.
- 단어별 기본/생활/부탁·질문 3단계 × 2문장 = 예문 240개. 영어 듣기와 한국어 뜻 표시/숨기기.
- 단어별 6장면 상황 대화 40개. 단어에 해당하는 참고 사진을 사용하며 대화 장면을 직접 촬영한 사진처럼 표시하지 않는다.
- 사진과 낱말, 문장 완성, 표현의 뜻, 대화 이해, 상황 순서 5문제. 연습 즉시 해설과 복습 마지막 채점.
- 단어별 한국 날짜 하루 첫 완료에만 보상 10포인트. 반복 풀이로 보상이 늘어나지 않는다.
- 퀴즈는 첫 시도 정답 수를 기준으로 100점 만점 점수와 별 0~5개를 보여 준다. 틀려도 포인트를 차감하지 않는다.
- 강아지·고양이·토끼 학습 친구와 기존 책/나침반/연필 표식, 이름·색상으로 학습카드를 꾸민다. 모든 캐릭터는 포인트 소비 없이 고른다. 새 프로필 기본 캐릭터는 토끼다.
- 홈에는 선택한 학습 친구, 누적 포인트와 배운 단어 수를 표시한다. 캐릭터는 정적인 이모지이며 외부 이미지/API나 애니메이션을 추가하지 않는다.
- 부모 확인, 단계/영어 속도/참고 시간 목표, 복습 추천, 최근 기록, 사진별 출처와 이용 조건, 영어 기록만 초기화.

추가 예문과 대화는 직접 작성한 짧은 문장이다. “Can I play with you?”, “Is it my turn now?”처럼 실제 생활에서 사용하는 표현을 다루며 출판된 영어책에서 인용했다고 표시하지 않는다. 영어책처럼 소리 내어 읽기 쉬운 반복 문형을 사용한다.

## 사진의 출처와 라이선스

실제 촬영 사진을 로컬 `public/english-photos/`에 저장했다. 40개 단어에 서로 다른 사진 40장을 연결한다. 창문은 창틀이 보이는 클로즈업 사진이고, ball은 농구공 실물 사진, soccer는 별도의 축구공 사진이다. 경로와 실제 JPEG 해시가 모두 단어별로 고유한지 콘텐츠 테스트에서 검사한다. 사진은 낱말의 참고 자료이며 대화 장면을 촬영한 사진이라고 주장하지 않는다. 비눗방울 사진은 얼어붙은 방울, 사다리 사진은 실내 사다리이며 수업 설명에서 구분한다. 단어 사진에는 일러스트·AI 이미지·영상·외부 이미지 핫링크를 사용하지 않는다. 동화 표지와 본문은 사진 단어와 구분되는 고전 삽화풍 창작 이미지다.

모든 원본은 Wikimedia Commons 파일 설명 또는 공개 사진 코퍼스의 개별 매니페스트에서 CC0 1.0으로 공개된 자료다. 기존 사진 9개의 경우 원본을 배포하는 공개 저장소 [libphash-site-corpus](https://github.com/gudoshnikovn/libphash-site-corpus)의 사진과 `corpus_photos.tsv`를 읽어 SHA-256을 대조했다. 기존 사진은 GitHub 배포 경로에서, 새 사진 29개는 Commons 미리보기 URL에서 다운로드했다. Commons 파일 설명도 웹 조회로 확인했으며, 자동차 사진은 파일 설명 조회 도구가 응답하지 않아 코퍼스의 개별 CC0 선언과 해시를 근거로 기록했다.

`lib/forest/photo-credits.json`에 원문 파일명, 저작자/촬영자, CC0 링크, 원문 페이지, 배포 경로, 원본/로컬 SHA-256, 변경 사항을 기록했다. 의자 사진은 제작자 Georges Jacob과 촬영자 Jebulon을 구분한다. 크기를 최대 1100px로 줄이고 JPEG 압축·EXIF 제거만 수행했으며 사물 합성은 하지 않았다. 추가 사진은 Commons `imageinfo`의 CC0 이용 조건과 저작자 메타데이터를 확인한 뒤 미리보기를 내려받아 최대 1000px로 압축했다. 추가 항목의 SHA-256은 내려받은 미리보기 원본과 최종 JPEG 각각을 기록한다.

CC0는 촬영물의 이용 조건이다. 사진 속 물건과 상표에 관한 모든 별도 권리까지 포기되었다고 주장하지 않는다. 노트북·의자는 예전 모델/장식 의자이며 현대 교실 사진이라고 표시하지 않는다. 표지판은 제한 속도 표지판으로, 정지 표지판으로 오인시키지 않는다. bowl의 사진은 그릇 모양을 가르치며 내용물을 먹으라고 안내하지 않는다.

## 비용과 개인정보

외부 AI·임베딩·TTS·이미지 생성 API, 이미지 CDN, 계정/DB 호출 없이 정적 콘텐츠와 로컬 사진으로 학습한다. 사이트의 AI API 비용은 0원이며 호스팅/전송 비용은 별개다.

영어 듣기는 브라우저 Web Speech API를 사용한다. en-US를 우선 선택하고 다른 영어 음성을 대안으로 사용한다. 한국어 음성으로 영어를 잘못 읽지 않는다. 영어 음성이 없으면 안내하고 글 학습을 계속한다. OS/브라우저가 음성을 온라인 합성할 수 있으므로 완전 오프라인 음성까지 보장하지는 않는다. 녹음·발음 판정·마이크 전송은 없다.

화면 제목은 Fun To Run이지만 기존 기록을 보존하기 위해 저장 키는 바꾸지 않는다. 영어 프로필 키는 `wordforest-english-v1`이다. 영어 프로필이 없을 때만 기존 `wordforest-v1`에서 별명·포인트을 가져오고 기존 키는 변경하지 않는다. 기존 한글 수업은 현재 화면에 표시하지 않는다. 영어 기록 삭제 시에도 기존 한글 키는 남는다. 기기 간 동기화는 없다.

## 동화책장과 게임 놀이터

홈의 큰 모험 카드와 하단 **동화 / 게임** 메뉴에서 바로 연다. 하단 메뉴는 홈·사진 단어·동화·게임·학습카드의 5개로 정리하고, 기존 상황 영어·퀴즈는 생활 영어 화면 위쪽의 빠른 연습 메뉴로 유지한다.

이솝우화·전래동화·세계 명작 30편을 각각 영어·한국어 8장면으로 읽는다. 기존 창작 동화 6편은 책장에서 교체했다.

- **토끼와 거북이**: 이솝우화. 꾸준함과 겸손을 배운다.
- **사자와 생쥐**: 이솝우화. 작은 친구도 서로 도울 수 있다.
- **금도끼 은도끼**: 한국 전래동화. 정직하게 말하는 마음을 배운다.
- **아기 돼지 삼 형제**: 영국 전래동화. 꼼꼼히 준비하고 서로를 지킨다.
- **미운 아기 오리**: 안데르센, 1843. 자신의 모습과 소중함을 알아간다.
- **벌거벗은 임금님**: 안데르센, 1837. 솔직하게 말하는 용기를 배운다.

추가 24편: 여우와 포도, 개미와 비둘기, 북풍과 태양, 개와 그림자, 까마귀와 물병, 시골쥐와 도시쥐, 여우와 두루미, 나뭇가지 묶음, 개미와 베짱이, 양치기 소년, 여우와 까마귀, 빨간 암탉, 달콤한 죽, 골디락스와 곰 세 마리, 빨간 모자, 브레멘 음악대, 신데렐라, 잠자는 숲속의 공주, 백설공주, 장화 신은 고양이, 어부와 금붕어, 구두장이와 요정, 완두콩 공주, 잭과 콩나무.

책장은 짧은 비율의 삽화형 표지를 앞면으로 진열하는 서점 갤러리다. 표지 상단은 4:3 삽화, 하단은 제목 띠로 구성해 긴 여백을 줄였으며 난이도·장면 수·읽기 상태도 두 줄로 표시한다. 데스크톱은 최대 5열, 태블릿은 3~4열, 아이폰은 2열로 표시하고 각 행 아래에 나무 선반을 표현한다. 제목·장르·난이도·8장면 안내와 이어 읽기/완독을 표시한다. 한국어/영어 제목과 장르 검색, 결과 없는 상태와 초기화, 난이도 필터를 지원하며 책장에서 고른 필터는 책을 읽고 돌아와도 유지한다.

난이도는 편집상 영어 문장 길이와 어휘를 기준으로 쉬움·보통·도전 각 10권으로 나눴다. 표준 시험 등급이 아니며 쉬움은 짧은 문장과 익숙한 낱말, 보통은 이야기 흐름 읽기, 도전은 긴 문장과 새로운 낱말을 연습한다. 각 책의 표지와 본문 상단에 난이도를 표시한다. 모든 단계에서 한국어 뜻과 영어 듣기를 함께 사용할 수 있다.

저작권 보호기간이 지난 원전의 줄거리를 바탕으로 Fun To Run에서 영어·한국어를 직접 각색했다. 현대 출판사의 번역·삽화는 사용하지 않는다. 각 책에 원전 정보를 표시하며 7살 독자를 위해 잔인한 장면을 생략했다. 돼지 삼 형제의 늑대는 집을 무너뜨리지 못하고 떠나며, 미운 아기 오리는 다른 모습도 소중하다는 의미로 마무리한다.

장면별 영어 듣기·뜻 숨기기·이야기 속 단어·이어 읽기·완독 표시를 제공한다. 사진 단어에 있는 어휘는 기존 학습 화면으로 연결하고 새 어휘는 뜻과 단어 듣기를 제공한다. 본문 240장면은 각 이야기의 진행에 맞춰 만든 수채화·판화풍 AI 창작 삽화를 로컬 `public/story-scenes/<tale-id>/01.webp`부터 `08.webp`까지 저장해 표시한다. 같은 책 안에서 장면마다 다른 삽화를 사용하며 동물·인물의 모습을 일관되게 맞췄다. 이미지 전체를 보여 주어 인물의 얼굴이나 주요 내용이 잘리지 않도록 한다. 홈의 동화 미리보기에도 같은 삽화 체계를 사용한다. 책장 표지는 별도로 만든 고전 수채화·판화풍 AI 창작 삽화 30개를 로컬 `public/book-covers/`에 저장해 사용한다. 기존 출판사 표지나 역사적 원본 삽화로 표시하지 않는다. 이미지 생성은 개발 중에만 수행하며 사이트 이용 중 생성 API를 호출하지 않는다. 외부 콘텐츠 API를 호출하지 않는다. 음성은 기존 브라우저 영어 읽기 설정을 공유하고 장면이나 메뉴를 바꾸면 멈춘다.

기존 포인트·캐릭터·단어·게임 기록과 교체 전 동화의 완독 내역은 유지한다. 새 책은 다른 ID로 관리하므로 처음부터 읽으며, 예전 책의 북마크가 새 책으로 이어지지 않는다.

미니게임 4종은 마우스·터치·키보드로 조작한다.

- **영어 골! 축구 챌린지**: 축구장에서 쓸 생활 영어 10개 중 무작위 5개에 도전한다. 한국어 미션에 맞는 영어 표현을 골라 슛하면 골/선방 애니메이션을 보여 준다. 오답은 힌트를 보고 다시 찰 수 있고 영어 듣기·텍스트 힌트·키보드/터치 조작을 지원한다. 5골 완주 50점에 첫 슛 정답마다 10점을 더하며 기존 최고 기록·하루 첫 완료 10포인트에 연동한다.
- **짝꿍 카드**: 사진 4장과 영어 낱말 4장의 짝을 찾는다. 틀린 짝은 아이가 직접 다시 뒤집을 때까지 보여 준다. 100점에서 틀린 짝마다 10점을 빼되 완료 점수는 최소 50점이다.
- **소리 탐정**: 5개의 영어 낱말을 듣고 사진을 고른다. 영어 음성이 없어도 단어 힌트로 플레이할 수 있다. 끝까지 풀면 기본 50점에 첫 시도 정답마다 10점을 더한다.
- **문장 기차**: 낱말 버튼을 눌러 5개의 생활 문장을 만든다. 선택한 낱말 되돌리기·다시 만들기·듣기 힌트를 지원하며 드래그가 필수인 동작은 없다. 완료 기본 50점에 첫 시도 정답마다 10점을 더한다.

제한시간·하트 차감·구매는 없고, 재도전과 오답 수정에 학습 포인트를 차감하지 않는다. 각 동화/게임은 한국 날짜 기준 하루 첫 완료에만 10포인트를 지급한다. 같은 날 재도전은 해당 활동의 최고 점수만 갱신하며 추가 포인트를 주지 않는다. 게임 기록은 일일 활동 단위 최근 180개까지 저장하므로 반복 플레이로 오늘의 지급 기록을 밀어내지 않는다.

기존 영어 프로필에 `storyPages`와 `activityRecords`를 추가해 이전 이름·캐릭터·포인트·단어 기록을 유지한다. 이어 읽기·완료/최고 점수·포인트는 현재 브라우저에 저장되며, 게임 중간 라운드는 페이지를 새로 열면 다시 시작한다. 부모님 학습실에서 동화·게임 기록을 볼 수 있고 영어 프로필 초기화 시 함께 초기화한다.
